## 처음 한 번만 (세팅 순서)
1. **콘텐츠** → *JSON 일괄 업로드* → `content/bundles/` 의 파일 3개를 차례로 올리기 (중1 동아(윤정미) 8과 · 중2 동아(이병민) 9과 · 공통영어2 능률(민병천) 6과). "빈칸 자동 생성" 체크 유지. 한 파일에 2~3분 걸릴 수 있어요.
   - 각 유닛에 단어장·대화문·본문·본문 빈칸 4종·**예상문제(정답+해설)** 가 들어 있어요. 시험범위를 만들 때 기출 연도는 비워 두면(전체) 예상문제가 모두 포함됩니다.
2. **학생 계정** → 엑셀에서 `이름 | 학교 | 학년 | 반 | 아이디 | 초기 비밀번호 | 출판사` 열을 복사해 붙여넣고 *계정 만들기*.
   - 학생은 회원가입 없이 이 아이디·비밀번호로 로그인합니다. 출판사를 지정해야 그 출판사 유닛만 보입니다.
3. **시험범위** → *새 시험범위*: 학교·학년·시험일·출판사 선택 → 범위 유닛 체크 → 포함 자료·기출 연도 입력 → 저장.
   - 같은 학교·학년 학생 홈에 **"내 시험범위" 카드 + D-day + 진도율 4개**가 자동 표시됩니다.

## 평소 운영
| 하고 싶은 일 | 어디서 | 방법 |
|---|---|---|
| 숙제 내기 | **숙제·수업** | 반·유닛·자료(·난이도)·마감일 고르고 *📝 숙제로 배정* → 학생 홈 "오늘의 숙제"에 표시, 다 풀면 자동 완료 |
| 수업 중 같이 풀기 | **숙제·수업** | *📢 지금 수업에서 풀기* → 그 반 학생 홈 맨 위에 10초 안에 카드가 뜸. 끝나면 *종료* |
| 진도 확인 | **진도율** | 시험범위 선택 → 학생 × 4항목 표 (빨강 0~49 / 노랑 50~79 / 초록 80~100). 반 필터, 진도 낮은 순, *CSV 내보내기* |
| 많이 틀린 문항 | **오답 분석** | 반별 TOP 10 + 학생별 오답노트 (남음/해결, 오답 횟수) |
| 비밀번호 잊음 | **학생 계정** | 해당 학생 줄의 *비번 초기화* |
| 자료 수정 | **콘텐츠 → 유닛 편집** | 탭별로 단어·대화문·본문·기출을 칸에서 바로 수정 (수정 후 다른 곳 클릭하면 저장) |
| 빈칸 문항 손보기 | **콘텐츠 → 빈칸 문항** | *자동 생성* 다시 실행, 또는 *직접 빈칸 지정*에서 문장의 단어를 클릭해 빈칸 추가. 정답 칸에 `a / b` 로 복수 정답 |
| 오답 해결 기준 | **설정** | 오답 재풀이에서 연속 1·2·3번 맞히면 "해결됨" |
| 학생 화면 확인 | **학생 화면 보기** | 학생과 같은 화면으로 자료를 열어볼 수 있음 |

## 학생 화면 요약 (학생에게 안내)
- **홈**: 내 시험범위·D-day·진도율, 오늘의 숙제, 오답노트 남은 개수, (수업 중) 지금 수업 자료
- **학습**: 유닛 → ①단어장 ②단어테스트(한→영/영→한, 10·20·전체, 랜덤) ③대화문 ④대화문 빈칸 ⑤본문 ⑥본문 빈칸(우리말 빈칸·영문 빈칸·동사형·어법 선택 = EXAM4YOU 워크북 2·3·5·6) ⑦기출문제
- 틀리면 바로 **정답 + 해설**이 보이고, 오답노트에도 💡해설이 같이 저장돼요 (문법·동사형은 규칙 설명, 나머지는 정답 문장 전체와 해석)
- **오답노트**: 틀린 문항 자동 저장 → *오답만 다시 풀기*, 유형·유닛 필터, 많이 틀린 순. 결과 화면마다 *틀린 문제만 바로 다시 풀기*
- 🔊 버튼: 단어·문장 발음 듣기 (브라우저 음성)

## 채점 규칙 (자동)
대소문자·문장부호·앞뒤 공백 무시 · 축약형 = 원형 (`I'm` = `I am`, `don't` = `do not`) · 정답 여러 개는 `/` 로 · 뜻 쓰기는 띄어쓰기 무시, 여러 뜻 중 하나만 맞아도 정답 · 객관식은 번호 · **철자 틀리면 오답**

## 문제가 생기면
- 학생이 유닛이 안 보임 → 학생 계정의 **출판사**가 비어 있거나 다른 출판사
- 시험범위 카드가 안 보임 → 학생의 **학교·학년**이 시험범위와 다름 (띄어쓰기까지 같아야 함)
- 숙제가 안 보임 → 학생의 **반** 이름이 숙제의 반과 다름 / 마감일이 지남
- JSON 업로드 오류 → 따옴표·쉼표 누락. `supabase/02_seed.sql` 안의 예시 형식과 비교
