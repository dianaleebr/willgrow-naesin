## 평소 운영
| 하고 싶은 일 | 어디서 | 방법 |
|---|---|---|
| 숙제 내기 | **숙제·수업** | 반 선택 → 유닛 체크(묶음별 *전체 선택*) → 자료 체크(*전체 선택*) → 마감일 → *숙제로 배정 (N개)*. 유닛×자료 조합마다 숙제가 하나씩 생기고, 목록에서 *이 묶음 삭제*로 한꺼번에 삭제 |
| 수업 중 같이 풀기 | **숙제·수업** | 유닛 1개·자료 1개만 고르고 *지금 수업에서 풀기* → 그 반 학생 홈 맨 위에 10초 안에 카드가 뜸. 끝나면 *종료* |
| 진도 확인 | **진도율** | 시험범위 선택 → 학생 × 4항목 표 (빨강 0~49 / 노랑 50~79 / 초록 80~100). 반 필터, 진도 낮은 순, *CSV 내보내기* |
| 많이 틀린 문항 | **오답 분석** | 반별 TOP 10 + 학생별 오답노트 (남음/해결, 오답 횟수) |
| 비밀번호 잊음 | **학생 계정** | 해당 학생 줄의 *비번 초기화* |
| 자료 수정 | **콘텐츠 → 유닛 편집** | 탭별로 단어·대화문·본문·기출을 칸에서 바로 수정 (수정 후 다른 곳 클릭하면 저장) |
| 빈칸 문항 손보기 | **콘텐츠 → 빈칸 문항** | *자동 생성* 다시 실행, 또는 *직접 빈칸 지정*에서 문장의 단어를 클릭해 빈칸 추가. 정답 칸에 `a / b` 로 복수 정답 |
| 오답 해결 기준 | **설정** | 오답 재풀이에서 연속 1·2·3번 맞히면 "해결됨" |
| 학생 화면 확인 | **학생 화면 보기** | 학생과 같은 화면으로 자료를 열어볼 수 있음 |

## 채점 규칙 (자동)
대소문자·문장부호·앞뒤 공백 무시 · 축약형 = 원형 (`I'm` = `I am`, `don't` = `do not`) · 같은 뜻의 표현은 정답 (`Can you` = `Could you` = `Would you`, `be going to` = `will`, `have to` = `must`, `would like to` = `want to`, `a lot of` = `many` 등) · 정답 여러 개는 `/` 로 · 뜻 쓰기는 띄어쓰기 무시, 여러 뜻 중 하나만 맞아도 정답, **품사가 같고 뜻이 비슷하면 정답 인정 + 정확한 뜻 표시** (예: refuse 정답 `~을 거부하다`에 `거절하다` → 정답, `거절`은 명사형이라 오답) · 객관식은 번호 · **철자 틀리면 오답**

- 숙제가 안 보임 → 학생의 **반** 이름이 숙제의 반과 다름 / 마감일이 지남
- JSON 업로드 오류 → 따옴표·쉼표 누락. `supabase/02_seed.sql` 안의 예시 형식과 비교

## 2026-10-03 업데이트
- **단어장 — 다의어·유의어·반의어 묶음**: WORD TEST 자료의 "다의어 & 유의어/반의어" 표를 단어장에 넣었습니다. 단어마다 `= 유의어`(초록) `↔ 반의어`(빨강) 칩이 붙고, 여러 뜻이 있는 단어는 **다의어 N** 표시와 함께 뜻마다 예문·해석을 펼쳐 볼 수 있어요. 위쪽 *전체 / 다의어 / 유의어·반의어* 버튼으로 묶어서 볼 수 있습니다. 어휘 목록에 없던 단어(유의어 표에만 있던 단어)는 `다의어·유의어` 분류로 추가됩니다.
- **단어테스트 새 모드**: *유의어·반의어*(단어와 뜻을 보고 유의어/반의어를 영어로 쓰기, 한 단어에 각각 한 문제) · *다의어*(예문 속 밑줄 친 단어가 그 문장에서 어떤 뜻인지 쓰기, 뜻마다 한 문제). 그 유닛에 해당 자료가 있을 때만 버튼이 보여요. 틀리면 오답노트에 `단어 · 유의어/반의어/다의어`로 저장되고 "틀린 이유 보기"에 유의어·반의어·여러 뜻이 정리돼 나옵니다.
